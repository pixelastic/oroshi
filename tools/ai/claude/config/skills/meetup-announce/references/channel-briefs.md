# Channel Briefs

## #office-paris

**Audience:** Colleagues in the Paris office.

**Angle:** You work here, this is happening in your space, come learn
and meet people. Help welcoming guests is appreciated but optional.

**Tone:** Casual, first-person. You're talking to coworkers.

**Structure:** Main message + thread reply.
- Main message: hook (topic explained concretely), talks overview
  (company names + what each covers), social proof (registration
  count), closing invitation to stay, raw registration link.
- Thread reply: full speaker list (first name, last name, company,
  talk subject), language and recording note, CTA emoji for headcount
  ("drop a :pizza:"), reminder that no registration is needed.

**Assets:** Attach to main message: event poster, teaser video,
program (all available assets). Give a visual sense of the event
without requiring people to read.

## #team-developer-marketing

**Audience:** Internal DevRel/marketing team.

**Angle:** Heads-up on what's being organized. Brand visibility,
coordination, metrics.

**Tone:** Informative, brief. Team context.

**Structure:** Single message, no thread.

**Assets:** Teaser video + header image.

## #help-recruiting

**Audience:** Recruiting team.

**Angle:** Ask if there are job openings to highlight at the event.
Employer branding opportunity: QR codes on screens, mention during
networking.

**Tone:** Direct ask. Short.

**Structure:** Single message, no thread.

**Assets:** None.

## topic-relevant

**Audience:** People interested in the meetup's subject matter.
Channel discovered at runtime via Slack search.

**Angle:** Come learn and network. If Algolia speakers are involved,
also mention partnership/sales opportunities. Ask for briefing on
Algolia's position in the topic if relevant.

**Tone:** Slightly more formal than office-paris. You're reaching
outside your immediate circle.

**Structure:** Single message, no thread.

**Assets:** Teaser video + image if Algolia speakers; image only
otherwise.
