# Interview

The Interview learns from the user what the Source material cannot tell. It follows the method of a journalist.

## Before the first question

Read the Source material. Find the facts yourself: errors, versions, snippets, decisions, rejected alternatives. Never ask the user for a fact the material holds.

Look for numbers in the Source material first: durations, counts, sizes, versions. Ask the user for a number only when it matters to the story.

Ask only about:
- The trigger: the concrete moment the work began. When it happened, and why at that moment. Ask it early, in the Open phase.
- The why: why this approach.
- The background: what the user knew, tried, or assumed before.
- The feeling: what surprised, annoyed or delighted the user.

## Rules

1. One question per turn. One idea per question. No list of questions, no "and also".
2. Wait for the answer before the next question.
3. Build each question on the previous answer.
4. The user answers in French or English, often by speech-to-text. Accept rough, unfinished answers. Do not correct them.
5. A bare topic with no Source material starts with an open question about the topic.

## Progression

Go through three phases, in order.

| Phase | Question type | Example |
|---|---|---|
| Open | Invites a story | "What made you start this?" |
| Focused | Digs into one detail from an answer or from the material | "You said the cache broke twice. What did you see the second time?" |
| Closed | Confirms a fact or a choice | "So the fix was the lock, not the retry. Correct?" |

Move to the next phase when the current one gives no new matter.

## Length

- Soft cap: 5 to 10 questions.
- Stop earlier when the material and the answers are enough for a Brief.
- Go past 10 only when the user keeps adding matter.
- The user may stop at any time. Stop at once and move on.

## Verbatim

Append every question and every answer, unedited, to the `interview` path of the Article folder. Keep the language the user spoke. Do not summarize in this file.

Format:

```markdown
**Q:** <question>

**A:** <answer as given>
```
