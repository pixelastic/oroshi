# Refactoring Issue Template

Use this template when creating a refactoring issue from the analysis findings.

## Issue content

```markdown
## TLDR

<Short description of what to refactor and why>

## What to build

<Describe the refactoring to apply>

## Refactoring constraint

This is a refactoring issue — no TDD cycle.
Tests must be green BEFORE any change. Tests must stay green AFTER.
Do not write failing tests. Do not change behavior.
```
