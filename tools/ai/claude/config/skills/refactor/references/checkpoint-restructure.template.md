# Final Checkpoint Template

Use this template to write the checkpoint issue for the `restructure` wave (final wave).

## Issue content

```markdown
## TLDR

Final refactoring checkpoint — triage remaining bugs and confirm completion.

## What to do

1. Read GUIDANCE.md `## Bugs found` for any remaining bugs.
2. For each bug, ask the user to choose:
   - **fix now** — create a bug-fix issue and add it to the plan. The bug-fix issue must include removing the bug entry from GUIDANCE.md `## Bugs found` after the fix.
   - **dismiss** — not a real bug. Remove it from GUIDANCE.md `## Bugs found`.
3. Confirm the refactoring arc is complete: reduce → rewrite → restructure done.
```
