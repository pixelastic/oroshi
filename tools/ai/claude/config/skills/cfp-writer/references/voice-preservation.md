# Voice-Preservation Rules (Review Mode)

When reviewing an existing draft, preserve the speaker's voice.

| Action                                        | Allowed? |
| --------------------------------------------- | -------- |
| Restructure and reorder                       | Yes      |
| Fix grammar, factual errors, cut filler       | Yes      |
| Add missing elements (hook, concrete example) | Yes      |
| Rewrite sentences that already work           | No       |

## Precedence

In review mode, these rules add to the `prose-writer` skill. When they
contradict it, these rules overwrite it.
