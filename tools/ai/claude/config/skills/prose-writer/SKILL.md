# Prose Writer

## Overview

Write prose in a consistent way that sounds like a person and reads without
effort.

**Core principle:** Write like a colleague talking, not like a manual.

Specialized prose skills use this skill as a base and add their own rules. If a
specific skill for the kind of text exists, use that one instead:

- **Slack**: Use `slack-writer` skill for Slack messages
- **Blog**: Use `blog-writer` skill for blog articles
- **Meetup recap**: Use `meetup-recap` skill for post-meetup recaps
- **CFP**: Use `cfp-writer` skill for conference proposals

## Core Workflow

### Step 1 — Sound human

**Goal:** Make the text read like a colleague talking.

**Exit criterion:** The draft follows every rule in `references/sound-human.md`.

Read [sound-human.md](./references/sound-human.md) and apply its rules to tone
and phrasing.

### Step 2 — Link ideas

**Goal:** Connect sentences by relation and remove ambiguous pronouns.

**Exit criterion:** The draft follows every rule in `references/links.md`.

Read [links.md](./references/links.md) and apply its rules to connectors and
pronouns.

## Common Rationalizations

| Rationalization                                 | Reality                                                         |
| ----------------------------------------------- | --------------------------------------------------------------- |
| "A specialized skill exists, but this is short" | Short text still follows its specialized skill. Use that skill. |
| "The draft is clear, so I can skip linking"     | Clear sentences still need relations. Run Step 2.               |

## Checklist

- [ ] No specialized prose skill fits the text
- [ ] Draft follows every rule in `references/sound-human.md`
- [ ] Draft follows every rule in `references/links.md`
