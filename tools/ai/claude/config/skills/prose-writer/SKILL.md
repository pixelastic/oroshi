# Prose Writer

## Disclaimer

If a specific skill for the kind of text exists, use that one instead:

- **Slack**: Use `slack-writer` skill for Slack messages
- **Blog**: Use `blog-writer` skill for blog articles
- **Meetup recap**: Use `meetup-recap` skill for post-meetup recaps
- **CFP**: Use `cfp-writer` skill for conference proposals

## Overview

Write prose in a consistent way, that sounds like a person and reads without
effort.

**Core principle:** Write like a colleague talking, not like a manual.

## When to Use

- Writing or rewriting a message, an email, or a document
- Editing a draft that sounds robotic
- Writing any text without a dedicated skill
