# Sound Human

Write like a colleague explaining something over coffee. The reader should not
guess that a tool wrote the text.

## Rules

- Write the way you would say it to a colleague, then tidy it.
- Use softeners when they are true: "I think", "probably", "as far as I can
  tell", "it seems".
- Use contractions: "it's", "don't", "we'll".
- Prefer plain words: "use" over "utilize", "help" over "facilitate".
- Say what you know plainly. Hedge only what you are unsure about.
- Avoid categorical, robotic phrasing: "It is imperative", "Always ensure",
  "Under no circumstances", "Please be advised".
- Avoid stock openers and closers: "I hope this finds you well", "Let me know if
  you have any questions", "In conclusion".
- Vary sentence length. Short sentences land. Longer ones carry a reason.

## Examples

- Bad: "It is imperative that the configuration be validated prior to
  deployment."
- Good: "Check the config before you deploy. A bad value breaks the build."

- Bad: "Please be advised that the meeting has been rescheduled."
- Good: "Heads up, the meeting moved to Thursday."
