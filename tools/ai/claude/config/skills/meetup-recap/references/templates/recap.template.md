# Recap Template

Format: a plain-text recap ready for Slack or email.

```
[introduction]

[what went well]

[what we learned]

[for next time]

[closing]
```

## Sections

### Introduction
Event name, date, attendance ratio, score, and format note. One short paragraph
— the reader should get the full picture without scrolling.

### What went well
Positive outcomes and wins. Use bullets if 2+, a single sentence if only one.
Skip entirely if nothing positive to report.

### What we learned
Real problems stated as facts. Same format: bullets if 2+, sentence if one, skip if none.

### For next time
Concrete fixes or action items for the next event. Same format.

### Closing
One sentence to wrap up. Light tone.

## Rules
- If a section has nothing, skip it entirely — no empty headers.
- Categorize the user's raw notes into the appropriate sections.
