## TLDR

Create `plan-end` script that stages plan artifacts and commits via `git-commit-message`.

## What to build

Create `scripts/bin/ai/plan/plan-end`. Takes one argument: the plan directory path. Stages everything in that directory and commits with a message generated by `git-commit-message`.

Minimal logic:
1. Validate plan directory exists
2. `git add <planDir>`
3. Generate commit message via `git-commit-message`
4. `git commit`

## Behavioral Tests

New tests — no prior art to migrate from (this script doesn't exist yet).

- exits 1 when plan directory doesn't exist
- calls git add with plan directory
- calls git-commit-message for the commit message
- creates a commit
